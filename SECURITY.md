# Security

Do not publish passwords, API tokens, private campaign data or personally identifying
information in issues. For a sensitive report, use the repository's private security
advisory feature when available, or contact its maintainer through their GitHub profile.

The dashboard is a local analysis tool. Add authentication, access control, upload
limits appropriate to your hosting environment, and a data retention policy before
using private customer information in a hosted deployment. No advertising platform
credentials or external account integrations are required for this project.
